# Вертикальные промо-кадры (9:16) — шортсы, Reels, TikTok, обложки видео

Кадры-обложки для вертикальных видео по игре. 10 штук: 8 — по районам вселенной
(01–07, 10), 2 — по ключевым механикам (фьюжн 3→1 и Cap Slam 3v3).

> **Сюжетная линия — в `heroes/`.** Второй набор про людей города, а не про фишки:
> один герой на район + промо города и эпизод «Ночь, когда город не спал»
> (`heroes/README.md`, `heroes/characters.json`, `heroes/EPISODE-01.md`).
> Этот набор (фишки/районы) остаётся как мир и механики.

| | |
|---|---|
| Формат | **1080 × 1920 (9:16)**, sRGB |
| Мастер (графика) | `promo/frame-XX-*.png` — без потерь, для монтажа и правок |
| Заливка в соцсети | `promo/jpg/frame-XX-*.jpg` — q92, без метаданных (450–800 КБ) |
| Сырьё модели | `raw/promo/frame-XX-*.png` (768×1376) — не удалять, из него всё перестраивается |
| Промты | `promo/prompts/XX-*.txt` — ровно те, что дали эти кадры (перегенерация 1-в-1) |
| Сценарии/подписи | `promo/frames.json` — хук, раскадровка по секундам, звук, подпись RU/EN, хэштеги |
| Пересборка | `bash scripts/promo-frames.sh` (все) или `bash scripts/promo-frames.sh 03` (один) |

## Как это совпадает с игрой

* **Лицо каждой фишки = арт района.** Мотылёк-трафарет (01), трюк через забор (02),
  вагон с движением (03), пара с ниткой (04), бумбокс (05), еноты (06), неоновая
  дверь на CRT (07), сшитый город на призме (10) — это те же сюжеты, что в
  `art_drafts/master/{d}-{r}.png` и в лоре `packages/economy/src/lore.ts`.
* **Палитра.** Асфальт `#16151A…2A2830`, акценты районов: cyan `#16E5D9`, orange
  `#FF7A1A`, magenta `#FF2E8A`, acid `#B6FF3C`, лёд `#9AD9FF`. `#2E8BFF`
  (trust-blue) в арт не попадает — это цвет денежного UI (`docs/07-art-spec.md`).
* **Обод по лестнице редкости.** Кадры сознательно показывают разные ступени —
  цинк → сталь → «бензиновая плёнка» → кракле-эмаль → бронза → призма, ровно как
  `RARITY_PROFILES` (`packages/economy/src/rarity.ts`).
* **Стихии.** В кадре 10 (Cap Slam) символы в лужах — колесо (wheels), ключ (steel),
  баллончик (paint), молния (noise) — кольцо из `packages/economy/src/pvp.ts`.
* **Никаких ошибок-обещаний.** В арте нет ни одного читаемого текста, логотипа,
  бренда или лица: имена, редкость и локализация живут в UI (7 языков), а не в
  картинке. Кадр 04 — про спасённую пару, но без «swoosh» и любых марок.

## Безопасные зоны (почему сверху/снизу темно)

Платформы сами рисуют поверх: прогресс-бар, ник, подпись, кнопки. Поэтому в
шортсах произведение должно быть тёмным в этих полосах — иначе текст не читается:

```
0     – 430 px   затемнение — ХУК (заголовок, 1–6 слов)            430 px
430   – 1330 px  сюжет: должен читаться за секунду свайпа
1330  – 1920 px  затемнение — подпись, субтитры, элементы платформы
```

Тёмные зоны уже впечены в файлы скриптом `scripts/promo-frames.sh` (градиенты,
зерно, грейд) — при монтаже поверх ничего дополнительно затемнять не нужно.

## Как пересобрать / перегенерировать

```bash
# одна картинка из сырья (кроп 9:16 → грейд → скрим-градиенты → зерно → PNG+JPG)
bash scripts/promo-frames.sh 06

# всё заново
bash scripts/promo-frames.sh

# контакт-лист для ревью (репорт, не коммитится)
montage art_drafts/promo/jpg/frame-*.jpg -tile 5x2 -geometry 216x384+6+6 \
  -background '#16151A' reports/contact-promo-frames.png
```

Скрипт детерминированный (ImageMagick 6, без сети). Из модели кадры выходят
768 × 1376; скрипт режет их до честного 9:16 (`768 × 1365`, срез сверху — там
небо и обрезаемые ножки), потом Lanczos-апскейл до 1080 × 1920. Сырьё — это
`raw/promo/frame-*.png`; перегенерация одного кадра описана в `frames.json`
(`status`), промт лежит рядом в `prompts/`.

## Что ещё не доделано

* **Кадр 04** — идёт перегенерация: у первого прогона лицо фишки получилось
  светлым (спека запрещает светлый диск — он «выжигает» тёмную сетку игры),
  в промте это уже зафиксировано явно.
* Нет кадров на `Legend+`/`Diamond` по районам (в таблице — 8 из 8 районов, но
  без редких ступеней отдельных коллекций) и нет версий 1:1 / 4:5 для статичных
  постов и внутренних баннеров — при необходимости собираются тем же скриптом
  с другим `-resize`/`-crop`.

Файлы не добавлены в игру и не участвуют в `assets:*` проверках: это
маркетинговый материал, он живёт только в `art_drafts/`. Если понадобится
раздавать их с лендинга — сообщите, положу в CDN-раскладку (`exports/cdn/`) с
хэш-именами, как требует `docs/07-art-spec.md` §4.
