# Kenney — Mini Skate (CC0)

3D-модели скейтера и скейтборда в `client/public/art/skate/`:

- `character-skate-boy.glb`, `character-skate-girl.glb` — ригged-персонажи с
  анимациями `skate`, `skate-stand`, `skate-air`, `skate-grab`, `jump`, `fall`,
  `die` и др.
- `skateboard.glb` — доска.

Источник: Kenney (www.kenney.nl), пак «Mini Skate», зеркало на GitHub —
`shorepine/kenney` (`3d/mini-skate/`). Лицензия ассетов Kenney — **CC0 1.0
Universal (public domain)**: можно использовать в коммерческих целях без
атрибуции; кредит ниже дан добровольно.

Модели используются как есть (файлы не модифицированы), рендер — three.js
(GLTFLoader), клипы выбираются по состоянию заезда движка economy:
едет → `skate`, воздух → `skate-air`, грэб → `skate-grab`, падение → `die`.
