# Трубы — входящий гидравлический модуль

Прислан пользователем 2026-10-18 (`files-2.zip`, коммит `be8f420`, папка
`incoming/files-2` в истории ветки) и внедрён в Floodgrid как экран
«Трубы района» (`/grid/pipes`, ссылка из раздела Flood на экране Grid).

Главное встраивание — в саму доску головоломки (никакой второй сцены):
`solveLevel` в `gutterNetwork.ts` считает по текущим поворотам скорость
воды в каждой трубе и клетки с открытыми концами, а `GridBoard`/`TileArt`
красят этим поток на самих тайлах: быстрые трубы несутся, едва
подключённые едва ползут, из открытых концов капает. Экран `/grid/pipes`
остался отдельным тренажёром модуля (насос/вентили/бак).

Состав:

- `pipeSolver.ts` — сетевой гидравлический решатель без зависимостей:
  Darcy–Weisbach (ламинарный 64/Re, турбулентный Swamee–Jain), Global
  Gradient Algorithm для всей сети, насосы по квадратичной кривой с
  законами подобия, вентили, форсунки, баки, кавитация по давлению пара.
- `pipeSolver.selftest.ts` + `pipeSolver.test.ts` — оригинальный селфтест
  (независимые пересчёты и законы сохранения), обёрнутый в vitest: падение
  любой проверки валит файл.
- `liquidShaders.ts`, `pipeScene.ts`, `PipeView.tsx` — three.js-сцена:
  стеклянные трубы, шейдерная жидкость с профилем скорости
  (парабола Пуазейля / степенной закон), уровни баков, кликабельные
  вентили и насос. Грузится лениво только на этом экране.
- `gutterNetwork.ts` — та же топология сети, переименована под ливнёвку
  района (коллектор, стояк, вентили A/C, 4 точки ливнёвки, бак).

Экономику не трогает: это песочница-визуализация поверх Floodgrid
(инвариант docs/16 §9). Тема сцены — `GUTTER_PIPE_THEME` в
`../PipesPanel.tsx`, оригинальная марсианская тема модуля сохранена в
`pipeScene.ts` (`MARS_LAB_THEME`) как запасной вариант.
