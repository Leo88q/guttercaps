## 0. Утверждённые правила (не пересматриваются без решения владельца)

### 0.1 Карта и маршрут
- [x] Все 75 уровней видны и играбельны сразу; сезонных ворот нет. (тренировка любого сектора — `mode:'training'`; серверный тест)
- [x] Зарядный проход фишки — строго по очереди: следующий уровень фишки = её `next_level`. (409 `route_locked`, тест)
- [x] XP за пару «фишка × уровень» — один раз в сумме (потолок = награда за 3 звезды); звёзды можно улучшать, XP добирается только разница.
- [x] Маршрут, уровень, заряд и «глубина спуска» принадлежат фишке (asset), а не владельцу: при продаже переходят покупателю. (таблицы по asset; маршрут виден на странице фишки и в листингах)
- [x] При fusion результат наследует объединение маршрутов материалов + суммарный XP (как `carryFusionXp`). (core `ChipFused` → `mergeFusionRoutes`, тест; claim-fusion: перенос при регистрации результата ✔ (`CompressedChipRegistered` → `mergeFusionRoutes`))

### 0.2 XP и звёзды
- [x] База уровня: `baseXP(L) = 4 + 2·L` (L=1 → 6, L=75 → 154; весь маршрут = 6 000 XP).
- [x] Звёзды по ходам: 3★ ≤ par; 2★ ≤ 1.5·par; 1★ ≤ 2·par; свыше — провал попытки.
- [x] Множители XP: 3★ = 100%, 2★ = 70%, 1★ = 40% (floor, минимум 1 за успех).
- [x] Провал зарядной попытки: −6 XP фишке-проводнику (как поражение на арене), не ниже чекпоинта (`applyChipXpDelta`).
- [x] Общий дневной кап 200 XP/фишка (арена + Решётка + билеты сверх капа — как сейчас `CHIP_XP.dailyCap`).
- [x] Недовыплаченный из-за капа XP не сгорает: остаток хранится и зачисляется позже без повторного прохождения. (`xp_pending`, тест)
- [x] Следующий уровень маршрута открывается при ≥ 1★; подарки — за достижение уровня вне зависимости от звёзд.

### 0.3 Заряд паводка (второй ресурс фишки)
- [x] 3 капли максимум; прогресс капли — за каждые 5 секторов маршрута, пройденных минимум на 2★.
- [x] Повтор уже пройденного сектора (≤1.5·par) доливает каплю — не чаще 1 раза в день на фишку; XP за повтор нет.
- [x] Арена: проигрыш сначала сжигает 1 каплю вместо −6 XP (по фишкам сквада). (`grantSquadXp`)
- [ ] Стейкинг: +5% веса за каплю (макс +15%); капля испаряется за 7 дней в стейке. Пул бюджетный — эмиссии сверху нет. — **Осталось**: вес считается on-chain программой стейкинга; бэкендом/клиентом это честно не реализовать, нужна фаза программы (или отдельный backend-root перераспределения). Константа `gridChargeStakeMult` в экономике есть.
- [x] Fusion: суммарный заряд материалов переходит в результат (макс 3).

### 0.4 Предметы «Снаряжение ныряльщика» (все — только за игру, не продаются)
- [x] «Метка Клеммы» (подсказка): точная ячейка + направление. В зарядной попытке макс 1; срезает потолок до 2★ (70% XP); вторая подсказка в попытке → попытка становится тренировочной (XP нет).
- [x] 3 провала зарядной попытки на одном секторе → 1 аварийная метка только на этот сектор. (тест)
- [x] «Аварийный клапан»: отменяет один штраф −6 XP за провал попытки. Запас ≤ 2.
- [ ] Запас меток ≤ 10; источники: старт 5 ✔; 3 сектора без подсказки +1 ✔; первая победа дня на арене +1 (≤3/нед) ✔; успешный fusion +1 ✔ (daily-квест `d_fuse1`); недельный маркет +1 ✔ (`w_trade`); недельный стейкинг +1 ✔ (`w_stake`: бустер + метка, показывается в квестах); подарки глубин ✔; Premium/Limited пак +1 (кап 1/день) ✔. — **Осталось**: метка из pass-трека (pass по существующему дизайну — только косметика, без игровых предметов; нужно отдельное решение, чтобы не ломать это правило).
- [x] Бесплатно всегда: % подключённости, статус приёмников, отмена хода, рестарт.

### 0.5 Подарки глубин (один раз на аккаунт, первая фишка на вехе)
- [x] 35: бустер fusion · 40: билет +100 XP (поверх капа) + 3 метки · 45: ваучер фишки шаблон 0 (80/18/2, SB 3 д)
- [x] 50: скин «мокрый ободок» · 55: 2 бустера + 3 метки ✔ · 60: тема профиля · 65: билет +100 XP ✔ · 70: баннер + титул · 75: ваучер шаблон 1 ✔ + печать «Сердце паводка». Скин (50) и тема (60) ✔ — настоящие earn-only entitlements, скин наносится на фишку (`POST /grid/apply-skin`), тема выбирается в профиле. Баннер (70) ✔ — district-banner района нырявшей фишки (витрина без требования полного сета), титул и печать (75) ✔ — entitlement kind-10, бейджи в шапке профиля.
- [x] Суммарные звёзды аккаунта: 75★ → 2 метки ✔; 125★ → клапан ✔; 175★ → 3 метки ✔; 225★ → скин «Идеальный паводок» ✔ (exclusive entitlement `perfect-flood`, наносится через apply-skin).

### 0.6 Режимы и события
- [ ] Кампания «Спуск» 75 (5 глубин × 15) ✔, Паводок дня (общий seed `dailySeed`, тренировка сектора дня) ✔. Район дня из Drain ✔ (та же ротация `day % 8`, приходит в `/grid/me.daily.district`). — **Осталось**: Контракты районов (фаза 3, отдельный гейт владельца в docs/12).
- [ ] «Ночь большого паводка»: недельная шкала района ✔ (`grid_flood`, очки = глубина), расчёт при чтении без крона ✔, награды предметами победившему району ✔ (метки/клапан). Воскресенье ✔: фишки района дня получают прогресс/добор капель ×2, паводок дня становится эпическим (сектор 75, 8×8).
- [x] Мастерство района + престиж фишки 75/75 («Сердце паводка» в фильтрах маркета). (`districtMastery`/`masteredChips` в `/grid/me`, фильтр `gridHeart` + бейдж в маркете)
- [ ] Призраки/контракты игроков (seed-вызовы) — фаза 3, награды только предметами в капах. (не начато)
