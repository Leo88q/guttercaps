# 14a. Решётка (Floodgrid) — инвентаризация арта поля и тайлов из Leo88q/1

> Статус: **перенос завершён, рендер-слой внедрён** (рендер и приёмка — в §7). Это чисто презентационный слой: механика (`packages/economy/src/gridEngine.ts`, `grid.ts`), бэкенд и цифры экономики не трогаются.
> Источник: репозиторий владельца `Leo88q/1`, ветка `arena/77b06826-1`. Арт там генерировался и отбирался владельцем специально под эту механику труб, палитра — из нашей `docs/07` §1–§2 (асфальт `#16151A`, magenta `#FF2E8A`, cyan `#16E5D9`, acid `#B6FF3C`, orange `#FF7A1A`; trust-blue `#2E8BFF` запрещён).

## 7. Реализация рендер-слоя и приёмка (шаги 2–3)

**Файлы клиента** (`client/src/features/grid/`): `gridArt.ts` — маппинг глубина→материал/URL, канонический поворот спрайта (`canonicalRotOf`), BFS-расстояние волны потока (`flowDistance`, синхронно с `poweredCells` движка), lazy-загрузка атласа с состоянием для фолбэка и idle-префетч следующей глубины (без `saveData`); `TileArt.tsx` — один спрайт-кадр + tint-поток маской того же атласа + маркеры ролей; `GridBoard.tsx` — сетка поверх фона глубины, повороты из `PlayState.vis` (накопленные визуальные четверти — мягкая анимация без «отмота через 270°»), взаимодействия неизменны (клик CW, правый клик/лонг-тап 450 мс CCW). Старый SVG-рендер остался внутри `TileArt` как автоматический фолбэк при недоступном атласе. CSS — блок `.gt*` + `--flow-accent` в `client/src/shared/ui/layout.css` (reduced-motion гасит пульс шины и волну потока: и «системный», и класс `html.reduced-motion`).

### 7.1 Рестайл поля (2026-10-14, решения владельца)

Правки по приёмке владельца; механика, движок и цифры не тронуты — меняется только слой отрисовки.

| Что было | Что просил владелец | Как сделано |
|---|---|---|
| Глубина 1 — цинк («большие разнородные» трубы) | убрать цинк из игры, уровни 1–15 — трубы из блока 5 | глубина 1 идёт набором `glass` (`GRID_DEPTHS`, §2); `GridTileSet`, звук, скрипты, лендинг и гайд очищены |
| Между трубами в собранном состоянии видна щель (на всех 75 картах) | стык должен читаться как соединение | три переменные стыка: `--gt-gap: 0` (зазор сетки), `--gt-pad: 0` (внутренний отступ ячейки), `--gt-zoom: 1.04` (спрайт и так идёт до кромки кадра — по оси трубы пустого поля 0 px, толщина 70/256; 4 % гасят муар на стыке); плюс фланец `.grid-tile::after` под трубой. | Пар, лучи и брызги «нигде не видны» | сделать их заметными | `.gt-ambient` — постоянный слой страницы: `SteamVeil` по низу + два `BeamPillar`; брызги `.gt-splash` — один проход в момент, когда клетка подключается к потоку (в `TileArt`, по переходу `powered`) |

| На мобильном мини-игра должна открываться во весь экран | полный экран при старте сектора | `.gt-fs` (`position: fixed`, без Fullscreen API — его iPhone не даёт): уровень стартует оверлеем, «Свернуть» (`grid.collapse`) возвращает на страницу; включается по `(max-width: 820px)`. `prefers-reduced-motion` и класс `html.reduced-motion` гасят и новое: полосы течения стоят, брызги не вспыхивают, шторка раскрывается без анимации. Критический путь бандла после правок — **347,0 КБ gzip** из 350 КБ (`npm run bundle:check`).
