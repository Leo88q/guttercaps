# 14a. Решётка (Floodgrid) — инвентаризация арта поля и тайлов из Leo88q/1

> Статус: **перенос завершён, рендер-слой внедрён** (рендер и приёмка — в §7). Это чисто презентационный слой: механика (`packages/economy/src/gridEngine.ts`, `grid.ts`), бэкенд и цифры экономики не трогаются.
> Источник: репозиторий владельца `Leo88q/1`, ветка `arena/77b06826-1`. Арт там генерировался и отбирался владельцем специально под эту механику труб, палитра — из нашей `docs/07` §1–§2 (асфальт `#16151A`, magenta `#FF2E8A`, cyan `#16E5D9`, acid `#B6FF3C`, orange `#FF7A1A`; trust-blue `#2E8BFF` запрещён).
> Контракт масок исходника **один в один** совпадает с нашим движком: N=1, E=2, S=4, W=8, поворот `((m<<1)|(m>>>3))&0xF` (их `packages/engine/src/tiles.ts` = наш `packages/economy/src/gridEngine.ts`). Канонические положения спрайтов: заглушка — 1, прямая — 5, отвод — 3, тройник — 7, крест — 15; визуальный поворот в клиенте — `rotationToReach(канон, текущая маска)` через CSS `rotate()`, т.е. один файл на форму, не четыре.
> Контакт-лист всех ассетов одной картинкой: `reports/14a-contact-sheet.png`. Сборка целевых файлов: `scripts/floodgrid-art-build.py` (результат — `client/public/art/grid/`, коммитится, деплою Python не нужен).

## 4. Чего нет в исходниках относительно целевого набора (шаг 2) — и как закрыто

| Нужно | В исходнике | Решение |
|---|---|---|
| Тайлы глубины 1 (цинк) | нет нарезки (канон их игры снят), есть листы | нарезаны их же `cut_pipes.py` из их же листов — §2 |
| Концевик цинка (`stub`, маска 1) | нет (ни при каком наборе; все `stub` в вебе собираются скриптом) | зеркало верхней половины прямой при сборке атласа — функция `make_stub`, та же схема, что у владельца |
| Состояние «под током» | в их игре красится средой слоями | наш вариант: tint-оверлей по альфе спрайта (`mask-image` тем же атласом) + `drop-shadow` — платные темы поля перекрашивают один цвет, а не набор спрайтов |
| Маркеры ролей (шина/приёмник/фикс./подсказка) | у них — артом (cap/mouth) | у нас — семантика текущего SVG: orange-ядро шины, циановое кольцо, серая точка, золотая рамка (CSS/inline-SVG поверх спрайта) |
| Повороты 0–3 | канон + формула | `rotate()` с накоплением визуальных четвертей (мягкая анимация, без разворота через 270°) |

## 5. Палитровый аудит

Автоматический линт (в `scripts/floodgrid-art-build.py`, порог 0,2 % синих пикселей) на целевых фонах: кадры 1a `0,02 %` (неоновые огни, розово-синие отблески — в допуске и под слоем сильного затемнения 55–70 %), остальные 9 кадров `0,00 %`. Тайлы — металл/стекло без синего. Электрических мотивов в тайлах нет (сантехника сверху); в фоне яруса 2 есть диодные лампы — это интерьер, не «ток в трубе». Перегенерация по палитре не потребовалась ни одной единице.

## 7. Реализация рендер-слоя и приёмка (шаги 2–3)

**Файлы клиента** (`client/src/features/grid/`): `gridArt.ts` — маппинг глубина→материал/URL, канонический поворот спрайта (`canonicalRotOf`), BFS-расстояние волны потока (`flowDistance`, синхронно с `poweredCells` движка), lazy-загрузка атласа с состоянием для фолбэка и idle-префетч следующей глубины (без `saveData`); `TileArt.tsx` — один спрайт-кадр + tint-поток маской того же атласа + маркеры ролей; `GridBoard.tsx` — сетка поверх фона глубины, повороты из `PlayState.vis` (накопленные визуальные четверти — мягкая анимация без «отмота через 270°»), взаимодействия неизменны (клик CW, правый клик/лонг-тап 450 мс CCW). Старый SVG-рендер остался внутри `TileArt` как автоматический фолбэк при недоступном атласе. CSS — блок `.gt*` + `--flow-accent` в `client/src/shared/ui/layout.css` (reduced-motion гасит пульс шины и волну потока: и «системный», и класс `html.reduced-motion`).

**Тесты** — `client/src/features/grid/gridArt.test.ts` (на реальных `generateLevel` 1–75: материалы глубин = `GRID_DEPTHS`, покрытие всех 5 форм, орбиты поворотов, `flowDistance ⇔ poweredCells`, инвариант креста). Бюджет: платные темы поля (`GRID_FIELD_THEMES`) теперь перекрашивают одну переменную `--flow-accent` — само поведение тем сохранено (выбор темы/логика хранения не тронуты, см. скриншоты magma/frost).

**Скриншотный харнесс** (воспроизводимо, не в продакшн-сборке): `client/shots.html` + `client/vite.shots.config.ts` + `client/src/features/grid/shots/main.tsx` (реальный `GridBoard` поверх реальных детерминированных уровней движка; сборка `npx vite build --config vite.shots.config.ts`, в среде `client/dist-shots`, gitignore) и раннер `scripts/grid-art-shots.mjs` (Playwright; в песочнице без CDN — `NODE_PATH` с `@sparticuz/chromium`).
