## Фаза 3. Бэкенд: прямой минт cNFT (без программы)

- ☑ **3.1 Билдер инструкции минта.** Backend строит Bubblegum
  `mintToCollectionV2` напрямую (web3.js + borsh, без chip_core):
  `backend/src/bubblegum-mint.ts` (метаданные из существующих шаблонов
  коллекций, leaf owner = покупатель, delegate = owner).
  Приёмка: юнит-тест раскладки инструкции (дискриминатор, аккаунты, args)
  на фикстурах; devnet-минт — п. 1.4 связкой.
- ☑ **3.2 Очередь минтов (кранк).** Заказы `paid` → минт n фишек заказа →
  `minted` с asset id; ретраи при фейле RPC, защита от двойного минта
  (статус + уникальный order_id в метаданных/журнале).
  Приёмка: тест — повторный прогон кранка не минтит дважды.
- ☑ **3.3 Журнал минтов + Verify.** Публичный журнал (order, asset, seed,
  rarity) и доработка `/verify`: пересчёт по журналу без ончейн-программы.
  Приёмка: API-тест журнала; клиентский Verify показывает запись журнала.
