## 2. Реализовано для воронки (эта сессия)

- **Гостевой демо-режим**: кнопка «Играть как гость» на лендинге → вся игра
  на встроенном моке без кошелька, с кислотным баннером «демо, покупки
  имитируются» и выходом в подключение (`client/src/api/client.ts: isDemo`,
  `Shell.tsx: demo-banner`). Ревьюер и новый игрок видят игру за 10 секунд,
  не тапая кошелёк. Демо честно помечено — за настоящий режим не выдаётся.
- **«Оценить игру»** в профиле: ссылка на листинг стора, рендерится только
  когда задан `VITE_DAPP_STORE_URL` (после публикации). Мёртвых кнопок нет.

## 3. Прод-окружение (перед mainnet-сборкой)

- [ ] `VITE_CLUSTER=mainnet-beta`, прод `VITE_RPC_URL` (Helius), `VITE_CG_MINT`,
      `VITE_PROGRAM_*` после деплоя программ.
- [ ] `VITE_FLAG_AGE_GATE=true` (и гео по выбранным рынкам) — в ранбуке
      превью стоят `false`, для денежного запуска включить.
- [ ] **Helius: ограничить API-ключ по доменам** (панель Helius → Allowed
      Origins: прод-домен + localhost). Ключ в бандле публичен по дизайну
      Vite — доменный allowlist единственная защита.
- [ ] `VITE_DAPP_STORE_URL` — после появления листинга (включит «Оценить игру»).
- [ ] Денежные ставки арены: решить флаг отключения вагеров для сторной
      сборки (политика гемблинга) — рейтинговые матчи не трогаем.

## 4. ⛔ Юридический блокер (не решается кодом)

`docs/legal/LAUNCH-READINESS.md`: оператор (юрлицо/страна/контакт издателя)
не определён, `LEGAL_REVIEWED=false`. Форма Publisher Portal требует
правдивые имя издателя, сайт и email. **Нельзя** подставлять выдуманную
компанию или адрес. Минимум для подачи: реальный издатель (ИП/компания),
публичный email поддержки, те же реквизиты в Terms. Это решение владельца,
не разработки.
