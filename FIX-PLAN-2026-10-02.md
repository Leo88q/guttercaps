# План закрытия находок аудита 2026-10-02

Делливерабл аудита: `AUDIT-2026-10-02.md` (20 находок: 1 high, 12 medium, 7 low).
Этот документ — варианты закрытия по каждой находке. Ничего не реализовано: жду апрувов.

**Условные обозначения.** «Правит» — список файлов, которых касается изменение. «Раскладка» — меняется ли
`#[account]`-раскладка какого-либо состояния (тогда обязателен `npm run state:layout -- --write` +
запись миграции; иначе `npm run state:layout` упадёт). «Человек» — закрытие невозможно без ответа
вне репозитория. Оценка: S ≈ до 3 файлов, M ≈ 4–10, L ≈ больше 10 или новый контрактный путь.
